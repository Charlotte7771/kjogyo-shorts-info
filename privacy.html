개인정보 및 Google 데이터 처리 안내

대상 프로그램: K조교 쇼츠 빠른 업로드
안내 기준: 2026년 11월 2일

사용하는 Google 데이터

운영자가 승인한 YouTube 권한으로 자신의 채널 ID와 이름, 영상 정보, 공개 범위, 댓글 및 조회수 등 요청한 작업에 필요한 정보를 확인합니다. 선택한 영상 파일과 제목·설명·해시태그·댓글 본문을 YouTube에 전송합니다. Google 계정 비밀번호를 프로그램이 수집하거나 저장하지 않습니다.

사용 목적

해당 채널에 영상과 기사 출처 댓글을 게시하고, 전송 상태를 확인하며, 같은 작업을 중복 수행하지 않기 위해 데이터를 사용합니다. 운영자가 설정한 경우 공개 24시간 뒤 조회수를 한 번 확인해 공개 범위를 조정합니다. Google 사용자 데이터를 광고, 판매 또는 AI 모델 학습을 위해 사용하지 않습니다. Google API에서 받은 정보의 이용은 Google API Services User Data Policy의 Limited Use 요건을 따릅니다.

저장과 전달

연결용 액세스·갱신 토큰은 운영자의 Windows PC에서 현재 Windows 사용자용 암호화 저장소에 보관합니다. 작업 파일과 전송 영수증도 해당 PC에 보관합니다. YouTube에 전송한 영상·설명·댓글은 운영자가 정한 공개 범위로 Google 서비스에 저장되며, 공개로 게시한 콘텐츠는 다른 사람이 볼 수 있습니다. 이 안내 사이트에 토큰, 대본, 영상, 사진 또는 작업 로그를 업로드하지 않습니다.

보관과 연결 해제

로컬 작업 기록과 파일은 운영자가 직접 관리합니다. Google 계정의 연결된 앱 관리에서 프로그램의 접근 권한을 취소할 수 있습니다. 권한을 취소해도 이미 YouTube에 저장된 영상과 댓글이 자동 삭제되지는 않으므로 YouTube Studio에서 별도로 관리합니다.

이 안내 사이트

이 사이트에는 자체 분석, 광고, 가입, 로그인 또는 입력 양식이 없습니다. 정적 페이지 호스팅 서비스가 사이트 제공을 위해 처리하는 접속 정보에는 해당 호스팅 서비스의 개인정보처리방침이 적용됩니다.
